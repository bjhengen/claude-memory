# Claude Memory MCP Server Dependencies

# MCP SDK. Capped below 2.0.0: mcp 2.x renamed FastMCP to MCPServer and moved it
# out of mcp.server.fastmcp, so `from mcp.server.fastmcp import FastMCP` in
# src/server.py raises ModuleNotFoundError. The cap is what keeps an unpinned
# rebuild from shipping a container that cannot import its own entrypoint.
# Lift it only together with the MCPServer migration:
# https://py.sdk.modelcontextprotocol.io/v2/migration/#fastmcp-renamed-to-mcpserver
mcp>=1.26.0,<2.0.0

# Every direct dependency is capped below its next major. An open range does not
# break when upstream publishes — it breaks at the next `pip install`, which for
# this repo is a Docker image build, i.e. mid-deploy. See the mcp note above.
# Caps below match the majors prod is actually running and CI actually tests.

# Database
asyncpg>=0.29.0,<1.0.0
pgvector>=0.2.0,<1.0.0

# OpenAI for embeddings. Prod runs 2.x; 3.0.0 is out and untested here, so the
# cap holds the line at the major this code was written against.

# ASGI server

starlette>=0.40.0,<1.0.0  # 1.0.0 dropped on_event() — pin until server migrates to lifespan

# Anthropic SDK for consolidation judge (v5). Prod runs 0.x; 1.0.0 is released
